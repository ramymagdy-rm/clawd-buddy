# Themes

Clawd Buddy has **38 themes**: 8 classic colour palettes and 30
characters, princesses and animals.

## Choosing one

- **While it runs:** the settings window's **Buddy** page, or the tray
  menu's **Theme** submenu (the characters, princesses and animals each
  have their own submenu below the line). The current theme is marked.
- **At launch:** `clawd-buddy --theme batman`

Your choice is remembered between launches, and `--theme` updates it
too. The first-run default is `dark`.
